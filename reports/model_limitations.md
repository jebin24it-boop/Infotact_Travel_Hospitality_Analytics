# Model Limitations and Future Improvements

## Current Limitations

- The models were trained on a single historical dataset.
- Hyperparameter tuning was not performed.
- Additional external factors such as weather, holidays, and local events were not included.
- Class imbalance handling techniques were not applied.

## Future Improvements

- Perform Hyperparameter Tuning using GridSearchCV or RandomizedSearchCV.
- Train ensemble models such as Random Forest and XGBoost.
- Apply Cross Validation for improved model generalization.
- Perform Feature Selection to optimize model performance.
- Develop a real-time hotel booking cancellation prediction system using Flask or Streamlit.
- Deploy the model as a web application for practical business use.

## Project Outcome

The developed machine learning pipeline demonstrates how predictive analytics can help hotels identify potential booking cancellations, improve operational planning, and support data-driven business decisions.
