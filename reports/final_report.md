# Final Project Report

## Objective

Predict hotel booking cancellations using machine learning techniques.

## Dataset

- Rows: 35,555
- Columns: 25
- Target Variable: booking_status

## Methodology

- Data Validation
- Feature Selection
- Label Encoding
- Train-Test Split
- Logistic Regression
- Decision Tree
- Model Evaluation

## Results

Both models were successfully trained and evaluated using Accuracy, Precision, Recall, F1 Score, ROC-AUC, and Confusion Matrix.

The better-performing model was selected based on overall evaluation metrics.

## Business Recommendations

- Monitor bookings with longer lead times.
- Improve customer retention programs.
- Optimize pricing strategies.
- Focus on high-risk market segments.

## Conclusion

The developed machine learning pipeline successfully predicts hotel booking cancellations and provides actionable insights for the hospitality industry.
